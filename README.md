# ZEROCHAT 🔒

**প্রাইভেট পিয়ার-টু-পিয়ার মেসেজিং ওয়েবসাইট**

কোনো অ্যাকাউন্ট নেই। কোনো লগইন নেই। কোনো ডাটাবেস নেই। মেসেজ সংরক্ষণ হয় না।

ZEROCHAT দুইজন মানুষকে সরাসরি (WebRTC DataChannel) চ্যাট ও ফাইল শেয়ার করতে দেয়। সার্ভার শুধু কানেকশন স্থাপনে (সিগন্যালিং) সাহায্য করে — চ্যাটের বিষয়বস্তু বা ফাইল কখনো সার্ভারে যায় না।

---

## ✨ বৈশিষ্ট্য

- **প্রাইভেট রুম** — শুধু দুইজনের জন্য
- **কোনো রেজিস্ট্রেশন নেই**
- **রিয়েল-টাইম টেক্সট চ্যাট**
- **ছবি, ভিডিও ও ফাইল শেয়ার** (সর্বোচ্চ ৫০ MB)
- **ফাইল ট্রান্সফার প্রোগ্রেস**
- **WebRTC DTLS এনক্রিপশন**
- **মোবাইল-ফ্রেন্ডলি বাংলা ইন্টারফেস**
- **ডার্ক / লাইট মোড**
- **ইন-মেমোরি রুম** (রিস্টার্ট হলে রুম মুছে যায়)

## ⚠️ গুরুত্বপূর্ণ সীমাবদ্ধতা (সততার সাথে)

1. **Railway / হোস্টিং প্রোভাইডার** ওয়েবসাইট ও সিগন্যালিং সার্ভার হোস্ট করে। তারা আপনার IP ঠিকানা, কানেকশন টাইম ইত্যাদি নেটওয়ার্ক মেটাডেটা দেখতে পারে।
2. **STUN সার্ভার** আপনার পাবলিক IP অন্য পিয়ারকে জানায়। STUN IP লুকাতে পারে না।
3. **TURN সার্ভার** ব্যবহার করলে ট্রাফিক TURN সার্ভারের মধ্য দিয়ে যায় (তবুও এনক্রিপ্টেড)। বেশি প্রাইভেসির জন্য নিজস্ব TURN চালানো ভালো।
4. **রুম ইন-মেমোরিতে** থাকে। Railway-তে নতুন ডিপ্লয় বা রিস্টার্ট হলে সব রুম মুছে যায়।
5. **নিরাপত্তা কোড** একটি সাধারণ যাচাইকরণ মাত্র। এটি পুরোপুরি ম্যান-ইন-দ্য-মিডল প্রতিরোধ করে না। আসল পরিচয় নিশ্চিত করতে অন্য মাধ্যমে (ফোন কল) কোড মিলিয়ে নিন।
6. WebRTC DTLS এনক্রিপশন কানেকশন সুরক্ষিত করে, কিন্তু **অন্য পক্ষ কে** তা সার্ভার বা অ্যাপ নিজে থেকে প্রমাণ করে না।

## 🚀 লোকালভাবে চালানো (বিগিনার গাইড)

### ১. Node.js ইনস্টল করুন
[https://nodejs.org](https://nodejs.org) থেকে LTS ভার্সন ডাউনলোড করে ইনস্টল করুন।

### ২. প্রজেক্ট ফোল্ডারে যান
```bash
cd ZEROCHAT
```

### ৩. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৪. সার্ভার চালু করুন
```bash
npm start
```

ব্রাউজারে খুলুন: [http://localhost:3000](http://localhost:3000)

### ৫. টেস্ট করুন
- একটি ট্যাবে রুম তৈরি করুন
- রুম আইডি কপি করুন
- অন্য ট্যাব/ডিভাইসে “যোগ দিন” দিয়ে একই আইডি দিন
- চ্যাট ও ফাইল টেস্ট করুন

## 🌐 Railway-তে ডিপ্লয় (ধাপে ধাপে)

1. [GitHub](https://github.com)-এ এই রিপোজিটরি পুশ করুন।
2. [Railway.app](https://railway.app)-এ অ্যাকাউন্ট করুন / লগইন করুন।
3. **New Project** → **Deploy from GitHub repo** সিলেক্ট করুন।
4. আপনার ZEROCHAT রিপোজিটরি বেছে নিন।
5. Railway স্বয়ংক্রিয়ভাবে `npm start` চালাবে এবং `PORT` সেট করবে।
6. ডিপ্লয় শেষ হলে Railway একটি পাবলিক URL দেবে (যেমন `https://zerochat-production.up.railway.app`)।
7. সেই URL ব্রাউজারে খুলে ব্যবহার শুরু করুন।

### Environment Variables (ঐচ্ছিক)

Railway ড্যাশবোর্ডে **Variables** ট্যাবে যোগ করতে পারেন:

| Variable          | বর্ণনা                                      |
|-------------------|---------------------------------------------|
| `PORT`            | Railway নিজে সেট করে                       |
| `TURN_URL`        | (ঐচ্ছিক) TURN সার্ভার URL                  |
| `TURN_USERNAME`   | (ঐচ্ছিক) TURN ইউজারনেম                     |
| `TURN_CREDENTIAL` | (ঐচ্ছিক) TURN পাসওয়ার্ড                   |

বর্তমান কোডে TURN ক্লায়েন্ট সাইডে `window.ZEROCHAT_TURN` দিয়ে সেট করা যায়। প্রোডাকশনে চাইলে সার্ভার থেকে কনফিগ ইনজেক্ট করা যায়।

## 📱 ব্যবহারবিধি

1. **রুম তৈরি করুন** → আইডি কপি করুন → বিশ্বস্ত ব্যক্তিকে পাঠান (WhatsApp/Signal/ইমেইল)।
2. অন্য ব্যক্তি **যোগ দিন** বাটনে আইডি পেস্ট করে জয়েন করবে।
3. কানেক্ট হলে **নিরাপত্তা কোড** মিলিয়ে নিন।
4. চ্যাট ও ফাইল শেয়ার করুন।
5. শেষ হলে রুম ছেড়ে দিন।
